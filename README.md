# Python Assignment 1

## Description
Solutions for **Assignment 1** from `Python_Programming_Assignment.pdf`, covering foundational Python syntax, variables, data types, type conversions, basic I/O, built-in functions, and core data structures.

- **Total Questions:** 50
- **Python Version:** Python 3.14+ (compatible with Python 3.x)

## Topics Covered
- `print()` statements, escape sequences, single-line and multi-line comments
- Valid and invalid Python identifiers and naming conventions
- Variables, multiple assignments, swapping values, and `id()`
- Core data types (`int`, `float`, `complex`, `str`, `bool`, `list`, `tuple`, `dict`)
- Type conversion (`int()`, `float()`, `str()`) and constructors (`list()`, `tuple()`, `dict()`)
- Built-in functions (`type()`, `len()`, `abs()`, `round()`, `pow()`, `min()`, `max()`, `sum()`, `input()`)
- Basic arithmetic formulas (areas, perimeters, volumes, simple interest, unit/temperature conversions)
